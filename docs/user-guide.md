# User Guide

## Launching Application

Open:
MusicStoreManagement_VBA_v1.0.xlsm
The Main Menu launches automatically.
---

## Inventory
Features:
- Add Record
- Search Record
- Update Re*ord
- Delete Record
---

## Sales
Features:
- Record Sale
- Search Sale
Recording a sale automatically reduces inventory.
---

## Dashboard
Displays:
- Total Inventory Value
- Total Revenue
- Total Sale
- Low Stock Records
---
## Reports
Available Reports:
- Inventory Report
- Low Stock Report
- Sales Report
- Revenue Summary

All reports are generated on the Reports worksheet.
