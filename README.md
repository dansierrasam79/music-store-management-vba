# Music Store Management System (VBA)
## Overview
A desktop-style business application developed in Microsoft Excel VBA for managing music inventory, sales transactions, reporting, and dashboard analytics.

## Features
###Inventory Management
- Add Records
- Search Records
- Update Records
- Delete Records

### Sales Management
- Record Sales
- Search Sales - Revenue Tracking
- Automatic Inventory Reduction

### Dashboard
- Total Inventory Value
- Total Revenue
- Total Sales
- Low Stock Monitoring

### Reports
- Inventory Report
- Low Stock Report
- Sales Report
- Revenue Summary

## Technology Stack
- Microsoft Excel
- Visual Basic for Applications (VBA)
- Excel Tables
- UserForms
- Object-Oriented Programming
